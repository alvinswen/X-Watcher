系统架构

核心功能

从数据采集到智能分发，覆盖信息监控全链路

🕸️
推文抓取
从 X 平台智能抓取推文，支持定时/手动触发。自动检测 Articles 长文，含重试退避、去重和数据质量校验。
TwitterAPI.io APScheduler 指数退避
🧠
AI 摘要 & 翻译
多 LLM 提供商摘要+中文翻译，自动故障转移。集中式优先级队列调度，内容哈希缓存避免重复调用。
6 提供商 智能降级 背压控制
📡
Feed 信息流
增量拉取 API，支持时间范围、多作者、关键词过滤。专为 AI Agent 设计的结构化输出格式。
增量查询 ISO 8601 Agent 友好
📅
推文浏览
按日期和作者维度结构化浏览。日历视图显示每日推文数，摘要/翻译/原文三合一展示。
日历选择 作者时间线 分页加载
🔍
推文搜索
多字段 AND 关键词搜索，覆盖正文、摘要、翻译、引用推文。支持作者和时间范围过滤。
多字段搜索 AND 逻辑 实时检索
📊
主题聚合
多账号推文聚合到主题，AI 生成综合分析报告。支持自定义 Prompt、时间窗口和所有权控制。
多账号 AI 综合 异步任务
🧩
聚类分析
基于 24h 发推时间分布的层次聚类（JSD + 平均链接法），识别发推行为模式，优化抓取调度。
scipy JSD 距离 热力图
🤖
MCP 服务
20 工具 + 5 资源，支持 stdio/SSE 双通道。三级权限分组，内置审计日志查询和工作流配方（如每日摘要生成指南）。
FastMCP stdio/SSE 配方资源
🛡️
防御性工程
Twitter API 熔断器（连续失败自动熔断）、僵尸任务启动恢复、MCP 操作白名单 Action Guard、全链路审计日志。
熔断器 审计日志 Action Guard
🔄
数据同步 & 回溯
JSON 文件导出/导入跨服务器同步，冲突策略（skip/overwrite/merge）+ dry-run 预览。Backfill 历史推文补抓并自动触发摘要。
导出/导入 Backfill 冲突策略
🖼️
Web 管理台
Vue 3 + Element Plus 企业级 UI，「墨纸」沉浸式阅读主题——宣纸配色、楷体字体、暗色模式。支持用户/账号/调度/主题/任务全方位管理。
Vue 3 Element Plus 墨纸主题

部署方案

从单机开发到生产部署，灵活适配不同场景

📦 SQLite 模式 开发
  • 零配置启动
  • WAL 模式 + 30s busy_timeout
  • Docker 持久化卷
  • 自动健康检查
bash
docker compose up -d
🚀 PostgreSQL 模式 生产
  • PostgreSQL 16 数据库
  • Alembic 自动迁移
  • 数据持久化 + 备份
  • 多阶段 Docker 构建
bash
docker compose --profile prod up -d
⌨️ CLI 命令 本地
  • pip install 一键安装
  • 交互式初始化向导
  • 配置校验 + 数据导入导出
  • 内置 uvicorn 启动
bash
pip install -e ".[dev]"
x-watcher init # 初始化配置
x-watcher serve # 启动服务
🤖 MCP 集成 Agent
  • stdio 模式（Claude Desktop）
  • SSE 模式（HTTP 远程）
  • 20 工具 + 5 资源
  • 内置工作流配方
bash
x-watcher mcp # stdio 模式
x-watcher mcp --mode sse
