# 产品概述

X-watcher 是一个**面向 Agent 的 X 平台智能信息监控服务**，通过结构化 API 为 AI Agent 提供 X 平台（Twitter）信息的采集、处理和分发能力。

## 核心能力

- **智能聚合** - 从 X（Twitter）平台抓取关注人物的动态，含 X Articles 长文自动检测与全文抓取
- **智能摘要** - 提取关键信息，生成简明摘要
- **英译中** - 将英文内容翻译为中文
- **摘要修复** - 支持批量补缺（为缺少摘要的推文生成摘要）和按时间范围重置（重新生成已有摘要）
- **用户管理** - 管理员可编辑用户信息（名称、邮箱、角色），包含最后管理员降级保护
- **主题所有权** - 每个主题关联创建者（user_id），非管理员只能查看和管理自己的主题及摘要任务，管理员可访问所有主题
- **用户档案缓存** - 自动同步并缓存 X 平台用户完整档案（头像、简介、认证状态、粉丝数等），每次抓取后自动更新，支持手动触发同步
- **抓取配置管理** - 管理员可查看账号运行时统计（effective_limit、近期最大新推文数），在线切换计算策略（自动/手动）和编辑单次抓取数量
- **运行时调度管理** - 管理员可通过 API 动态调整抓取间隔和下次触发时间
- **推文搜索** - 多字段关键词搜索（正文、摘要、翻译、引用推文），支持多关键词 AND 逻辑、作者筛选和时间范围过滤
- **推文浏览** - 管理员按日期和作者维度浏览推文，结构化展示摘要、翻译、原文
- **发文聚类分析** - 基于 24 小时发推分布的层次聚类，将监控账号自动分组，支持重切割和手动调整，优化抓取调度和摘要时机
- **系统状态概览** - 一站式获取推文、关注、摘要、主题、调度器和系统维度的关键指标，便于 Agent 了解数据时效性和系统健康状况
- **多 LLM 提供商** - 统一 OpenAI 兼容协议，支持 OpenRouter、MiniMax、DeepSeek、智谱、Moonshot 等 6+ 提供商，一键切换
- **数据同步** - JSON 文件导出/导入机制，支持跨服务器同步配置、推文、摘要和主题数据，含冲突策略（skip/overwrite/merge）和 dry-run 预览
- **CLI 工具** - `x-watcher init / validate / serve / export / import-data` 命令，Agent 或人类开发者一键完成安装配置和数据同步
- **配置验证** - 运行时验证 LLM 提供商、Twitter API、数据库的健康状态
- **结构化输出** - 所有数据通过 RESTful API 以 JSON 格式输出，便于 Agent 消费

## 目标用户

**AI Agent 和开发者**
- AI Agent 需要自动化获取 X 平台信息作为上下文输入
- 开发者需要构建基于 X 平台数据的智能应用
- 需要结构化、经过清洗的高质量数据源

## 核心使用场景

1. **Agent 自动化信息采集**
   - Agent 通过 Feed API 定时增量拉取处理后的推文数据
   - 支持按作者、关键词过滤，精准获取关注内容
   - 获取摘要、翻译一站式处理的结构化信息

2. **动态监控配置**
   - 通过 API 动态管理抓取配置和调度
   - 通过主题管理组织监控账号和摘要任务

3. **信息分发服务**
   - 为下游 Agent 或应用提供标准化的信息流
   - 支持增量拉取，避免重复处理

## 价值主张

与通用信息聚合器不同，X-watcher 的核心差异在于：

- **Agent 友好 > 人机交互**
  - RESTful API + JSON 输出，面向程序化消费
  - 增量拉取机制，适配 Agent 的定时调度模式

- **深度处理 > 简单聚合**
  - 摘要、翻译一站式完成
  - 减少信息噪音，提高信噪比

- **服务化 > 工具化**
  - 作为独立服务运行，支持多 Agent 并发调用
  - 标准化接口，可被任意 Agent 框架集成

## 未来扩展方向

- **数据源扩展** - 从 X 平台扩展到 Newsletter、RSS 等更多来源
- **MCP 集成** - 提供 Model Context Protocol 接口，直接对接 LLM 应用
- **Webhook 推送** - 支持主动推送新信息到 Agent 端
