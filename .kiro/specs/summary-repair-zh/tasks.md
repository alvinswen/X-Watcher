# Implementation Plan

- [x] 1. 为现有 API 端点添加认证保护
- [x] 1.1 为 Summarization API 的 6 个现有端点添加管理员认证
  - 为批量摘要、单条查询、统计、重新生成、任务查询、任务删除端点添加管理员认证依赖
  - 导入认证函数和用户模型，在每个端点函数签名中注入管理员认证参数
  - 确保现有功能不受影响，认证仅作为访问控制层
  - _Requirements: 3.2, 3.6, 3.7_

- [x] 1.2 (P) 为 Admin API 的 4 个端点添加管理员认证
  - 为抓取管理的启动、查询全部、查询单个、删除端点添加管理员认证依赖
  - 模式与 Summarization API 完全一致
  - _Requirements: 3.3, 3.6, 3.7_

- [x] 1.3 (P) 为 Tweets API 的 2 个端点添加管理员认证
  - 为推文列表和推文详情端点添加管理员认证依赖
  - _Requirements: 3.4, 3.6, 3.7_

- [x] 1.4 (P) 为 Deduplication API 的 5 个端点添加管理员认证
  - 为批量去重、去重组查询、推文去重状态、删除去重组、任务状态端点添加管理员认证依赖
  - _Requirements: 3.5, 3.6, 3.7_

- [x] 1.5 确认 Feed API 已有普通用户认证
  - 验证 Feed API 端点已使用普通用户认证（而非管理员认证）
  - 如有差异则修正，确保普通用户可访问 Feed
  - _Requirements: 3.1_

- [x] 2. 实现摘要补缺和重置的 Pydantic 模型
- [x] 2.1 添加补缺和重置的请求响应 Schema
  - 创建预览响应模型，包含受影响推文数量字段
  - 创建补缺请求模型，支持可选的时间范围参数
  - 创建补缺响应模型，包含任务 ID、状态和推文数量
  - 创建重置请求模型，必填时间范围参数，并校验起始时间必须早于截止时间
  - 创建重置响应模型，包含任务 ID、状态和推文数量
  - 重置请求的时间校验不通过时返回 422 错误
  - _Requirements: 1.1, 1.2, 1.3, 2.1, 2.2, 2.3_

- [x] 3. 实现摘要补缺和重置的 API 端点
- [x] 3.1 实现查询无摘要推文的辅助函数
  - 使用 LEFT JOIN 查询没有关联摘要记录的推文
  - 支持可选的时间范围过滤（基于推文发布时间）
  - 同时提供计数版本（用于 preview）和 ID 列表版本（用于 execute）
  - _Requirements: 1.1, 1.2_

- [x] 3.2 实现查询时间范围内推文的辅助函数
  - 按推文发布时间范围查询推文
  - 提供计数版本和 ID 列表版本
  - _Requirements: 2.1_

- [x] 3.3 实现补缺预览和执行端点
  - 预览端点接收可选的时间范围参数，返回缺少摘要的推文数量
  - 执行端点查询无摘要推文 ID 列表，创建后台任务进行摘要生成（不强制刷新）
  - 无需补缺时返回 404 错误
  - 通过任务注册表管理任务生命周期，返回任务 ID 供轮询查询
  - 所有端点要求管理员认证
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 3.2_

- [x] 3.4 实现重置预览和执行端点
  - 预览端点接收必填的时间范围参数，返回该时间段内推文数量
  - 执行端点查询时间范围内推文 ID 列表，创建后台任务强制重新生成摘要
  - 无推文时返回 404 错误
  - 通过任务注册表管理任务生命周期，与补缺共享相同的任务查询机制
  - 所有端点要求管理员认证
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5, 3.2_

- [x] 4. 后端测试
- [x] 4.1 编写摘要修复 API 的集成测试
  - 测试补缺预览端点：有/无时间范围、有/无缺失摘要的场景
  - 测试补缺执行端点：正常返回 202、空结果返回 404
  - 测试重置预览端点：正常查询、空结果、无效时间范围
  - 测试重置执行端点：正常返回 202、空结果返回 404、时间范围校验返回 422
  - 测试所有新端点的认证：无凭证返回 401、非管理员返回 403
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 2.1, 2.2, 2.3, 2.4, 3.2, 3.6, 3.7_

- [x] 4.2 (P) 验证现有端点添加认证后的回归测试
  - 确认 Summarization、Admin、Tweets、Deduplication 各模块现有测试在添加认证后仍能通过
  - 在测试 fixture 中适配认证依赖（mock 或注入测试 API Key）
  - _Requirements: 3.2, 3.3, 3.4, 3.5_

- [x] 5. Agent 工具注册
- [x] 5.1 (P) 注册摘要修复工具元数据和系统提示
  - 添加补缺工具元数据，描述端点、可选时间范围参数和管理员认证方式
  - 添加重置工具元数据，描述端点、必填时间范围参数和管理员认证方式
  - 在系统提示中添加摘要修复工具的使用说明，指导 Agent 在发现摘要缺失时自动触发补缺

- [x] 6. 前端 API 客户端扩展
- [x] 6.1 添加摘要修复 API 的 TypeScript 客户端方法
  - 添加补缺预览方法，通过 GET 请求传递可选时间范围参数
  - 添加补缺执行方法，通过 POST 请求提交补缺任务
  - 添加重置预览方法，通过 GET 请求传递必填时间范围参数
  - 添加重置执行方法，通过 POST 请求提交重置任务

- [x] 7. 前端摘要工具 UI
- [x] 7.1 在推文列表页添加摘要工具下拉菜单
  - 在批量操作区域添加下拉菜单组件，包含"摘要补缺"和"摘要重置"两个选项
  - 下拉菜单与现有的"批量摘要"、"批量去重"按钮并列

  - 确认执行后调用重置 API，通过轮询机制跟踪任务进度
  - 任务完成后自动刷新推文列表
  - 任务执行中禁用操作按钮，防止重复提交
