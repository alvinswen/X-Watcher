# 实现计划

- [x] 1. (P) 后端 Schemas 定义
  - 定义每日统计、作者信息、推文浏览条目等 Pydantic 响应模型
  - 包含日期字符串、推文数量、作者账号与显示名称、摘要、翻译、原文、引用推文、媒体附件等字段
  - 日期格式统一使用 `YYYY-MM-DD` 字符串
  - 分页响应包含总数、当前页、每页条数、总页数
  - datetime 字段继承 `UTCDatetimeModel` 基类处理 SQLite naive datetime
  - _Requirements: 1.6, 2.7, 3.8_
  - _Contracts: BrowseSchemas_

- [x] 2. 后端 BrowseService 实现
- [x] 2.1 (P) 实现每日推文数量统计查询
  - 按年月查询该月内每天的推文数量
  - 使用 SQLite `DATE()` 函数按日期分组聚合
  - 通过月份首尾日期构建时间范围过滤条件
  - 返回日期-数量的列表，无推文的日期不出现在结果中
  - _Requirements: 1.2, 1.6_
  - _Contracts: BrowseService.get_daily_stats_

- [x] 2.2 (P) 实现作者列表查询
  - 按指定日期查询当天有推文的所有作者
  - 聚合每位作者的推文数量和最后一条推文的时间
  - 使用关联子查询获取每位作者最新推文中的显示名称
  - 支持按最后活跃时间降序排序
  - _Requirements: 2.2, 2.3, 2.7_
  - _Contracts: BrowseService.get_authors_

- [x] 2.3 实现推文浏览列表查询
  - 按日期查询推文，支持可选的作者筛选参数
  - 使用 LEFT JOIN 关联摘要表获取摘要文本和中文翻译
  - 包含引用推文的原文、作者和媒体信息
  - 按发布时间正序（从早到晚）排列
  - 实现分页逻辑（总数查询 + 偏移量计算）
  - _Requirements: 3.6, 3.7, 3.8_
  - _Contracts: BrowseService.get_tweets_

- [x] 3. 后端路由端点与主应用注册
  - 定义三个 API 端点：每日统计、作者列表、推文浏览列表
  - 日期参数使用正则校验 `YYYY-MM-DD` 格式，无效格式返回 422
  - 月份参数校验 1-12 范围
  - 所有端点使用 admin 认证依赖
  - 将 browse 路由注册到主应用，路由前缀 `/api/browse`
  - _Requirements: 1.6, 2.7, 3.8, 5.5_
  - _Contracts: BrowseRouter API_

- [x] 4. (P) 前端类型定义与 API 客户端
  - 定义 TypeScript 接口：每日统计响应、作者信息、推文浏览条目、分页响应、请求参数
  - 实现 API 客户端模块，包含三个方法对应后端三个端点
  - 复用现有 HTTP 客户端基础设施
  - 在类型和 API 导出入口文件中注册新模块
  - _Requirements: 1.6, 2.7, 3.8_

- [x] 5. 前端推文浏览页面
- [x] 5.1 搭建页面布局与路由集成
  - 创建三栏布局：日历面板、作者列表面板、推文展示面板
  - 注册 `/browse` 路由到前端路由系统
  - 在管理后台侧边栏添加"推文浏览"菜单项和图标
  - 保持与现有管理页面一致的布局和视觉风格
  - _Requirements: 5.1, 5.2, 5.3, 5.4_

- [x] 5.2 实现日历面板与日期选择交互
  - 集成日历控件，在日期单元格上显示当天推文数量
  - 默认选中当天日期，页面加载时自动请求当月统计数据
  - 点击日期时加载对应日期的作者列表和推文列表
  - 通过监听年月变化检测月份切换，自动请求新月份的统计数据
  - 通过 CSS 调整日历控件尺寸以适配侧边栏宽度
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5_

- [x] 5.3 实现作者列表面板与筛选交互
  - 展示当前选中日期下有推文的所有作者，每位作者旁显示推文数量
  - 提供"全部作者"选项用于取消作者筛选
  - 点击作者时仅展示该作者的推文，点击"全部"时展示所有推文
  - 切换日期时重置作者选择状态
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5, 2.6_

- [x] 5.4 实现推文内容展示与条件作者信息
  - 按固定顺序展示每条推文：发布时刻、摘要、中文翻译、原文
  - 无摘要时跳过摘要部分，无翻译时跳过翻译部分
  - 展示引用推文的原文和作者信息（转推、引用、回复）
  - 展示媒体附件（图片等）
  - 未选定作者时，每条推文显示作者账号和显示名称
  - 选定作者时，推文列表顶部显示作者信息，推文中不重复显示
  - 实现分页控件进行翻页浏览
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 3.5, 3.6, 3.7, 4.1, 4.2, 4.3_

  - 测试空数据返回正确的空响应结构
  - 测试分页参数、作者筛选、日期范围边界
  - _Requirements: 1.6, 2.7, 3.8, 5.5_

  - 验证页面加载后日历默认选中今天并显示推文数量
  - 验证日期切换触发作者列表和推文列表刷新
  - 验证作者选择联动推文列表筛选
  - 验证作者信息条件展示逻辑（日期模式 vs 作者模式）
  - 验证分页翻页功能正常
